# Butler 界面视觉规范 —「安静的管家」

> 2026-10 界面去「AI 感」重构。本文档记录问题诊断、设计原则、设计 token 与改动清单。
> 历史方案见 `FRONTEND_MODERN_UI.md`（玻璃拟态 / UI 2.0，已废除其装饰性部分）。

## 一、为什么之前的界面有「AI 感」

「AI 感」不是某一个效果的问题，而是**一整套模板化视觉语言的堆叠**，缺少取舍与秩序：

1. **装饰性特效抢戏**：四角发光「虫洞门」、全屏粒子热力图背景、扫描激光线、呼吸光晕、
   发光状态点、渐变文字、跑马灯连线——都在「展示效果」，而不是「传递信息」。
2. **色彩无纪律**：24 张功能卡片各配一种高饱和图标色（#FF9500 / #34C759 / #AF52DE / #FF2D55 …），
   彩虹式配色让界面像 emoji 贴纸墙，重点反而不突出。
3. **Emoji 当装饰**：分区标题 `🚀 Butler 应用功能`、`🧰 本地技能`、指令文案里的 🔍🧹🎙️ 等，
   正式生产力工具极少用 emoji 做视觉装饰。
4. **模板化文案**：「你好，Butler」「开启极致本地优先的 AI 空间」「激光诊断」「跑马灯流动」——
   套话 + 炫技词，没有产品自己的语气。
5. **玻璃拟态滥用**：blur 30px / saturate 180% / 0.5px 亚像素边框 / 大面积半透明白，
   层级靠模糊而不是靠明度与边界，浅色主题下所有东西都「浮」在一起。
6. **命名与排版随意**：`Butler AI - Next Gen Matrix`、`智能助手 (Smart Chat)` 中英括注混写，
   字号字重缺少档位。

## 二、设计原则

**管家的性格：克制、秩序、可靠。** 界面退到内容后面，颜色只表意，不表演。

| 原则 | 落地 |
|------|------|
| 颜色只表意 | 单一强调色 + 状态色（成功/警告/危险），图标默认单色继承文字色 |
| 无装饰特效 | 移除粒子背景、虫洞光门、激光扫描线、发光阴影、渐变文字 |
| 表面分明 | 暖灰画布 + 纯白卡片 + 1px 边框，明度分层，不靠毛玻璃 |
| 字体系统 | 系统字体栈（中文优先 PingFang SC / Noto Sans CJK），字号字重走档位 |
| 几何档位 | 圆角 8 / 10 / 14px；阴影 3 档，仅表达层级 |
| 动效克制 | 0.2s 统一缓动，不弹跳不上浮；支持 `prefers-reduced-motion` |
| 文案诚实 | 说清楚功能是什么，不用「极致 / 魔法 / 智能空间」类词汇 |

## 三、设计 Token（`src/style.css` 顶部）

### 浅色（默认，`.theme-apple`）
- 画布 `#ECE9E2` · 表面 `#FFFFFF` · 次级表面 `#F7F5F0`
- 文字 `#22201B` / 次级 `#6B6558` · 边框 `#E0DBD1` / `#CAC4B6`
- 强调色 `#2F6B54`（墨绿）· 强调弱底 `rgba(47,107,84,.10)`
- 状态色：成功 `#35785A` · 警告 `#B07A22` · 危险 `#BB4A40`

### 深色（`.theme-dark`）
- 画布 `#171613` · 表面 `#211F1B` · 文字 `#EAE6DD` / `#98917F`
- 强调色 `#5FA98A`，状态色同语义换算

## 四、本次改动清单

**`src/style.css`**
- 重写 `:root` / `.theme-apple` / `.theme-dark` token：暖中性 + 墨绿强调

## 五、遗留事项

1. **次级界面仍是旧视觉**：下载管理器（`download/`）、PWA 翻译页（`pwa/`）、
   工作流中心（`workflow.html`）、视频库 / 播放器 / 截屏标注等仍有 emoji 与硬编码内联色。
2. **深色主题**仅完成 token 层，个别硬编码 `rgba(255,255,255,…)` 的组件需逐屏核对。
3. **信息层级**：技能仓储 / 设置页右侧大面积空白，需要布局层面的调整。
4. **快捷卡片密度**：24 张卡片平铺偏机械，可考虑按使用频率分层（常用 / 全部）或改列表。
5. 构建链：`tsconfig.json` 的 `rootDir` 与 `PyWebViewAPI` 类型声明有既有报错，
   `dist/bundle.js` 未在仓库内生成，建议补齐构建脚本。
